# 💧 Sistema de Monitoramento de Reservatório de Água

Projeto desenvolvido para a disciplina de **Desenvolvimento de Sistemas I (Agenda 11)** do curso Técnico em Desenvolvimento de Sistemas na **ETEC - Centro Paula Souza**.

## 📌 Descrição do Projeto
O sistema simula em terminal o controle de nível de um reservatório de água em cinco estágios distintos. Cada nível é associado a uma mensagem de alerta e destacado com uma cor específica utilizando a biblioteca `colorama`, com restauração do estilo do terminal ao final da execução.

## 🎨 Tabela de Níveis e Cores
| Nível | Situação | Cor no Terminal |
|---|---|---|
| Nível 1 | Muito baixo (crítico) | Vermelho |
| Nível 2 | Baixo | Amarelo |
| Nível 3 | Médio | Verde |
| Nível 4 | Alto | Ciano |
| Nível 5 | Muito alto (alerta) | Azul |
